front-end

FRONT END

Description

Le front-end est la partie du développement web qui me correspond le plus aujourd’hui. J’aime créer des interfaces propres, visuelles et interactives, en faisant attention à la structure, au responsive design et aux détails d’affichage.

Compétences principales

  • HTML pour structurer les pages.
  • CSS pour créer la mise en page, les animations et l’identité visuelle.
  • JavaScript pour ajouter de l’interactivité.
  • Vite.js pour organiser des projets web modernes.
  • Three.js pour intégrer des éléments 3D dans une interface.

En apprentissage

Je suis actuellement en train d’apprendre Vue.js afin de mieux structurer mes projets avec une logique de composants.

Objectif : progresser vers des interfaces plus propres, mieux organisées et plus proches d’un vrai environnement professionnel.

back-end

BACK END

Description

Le back-end représente la partie serveur d’une application web. Il permet de gérer la logique, les données, les traitements et les échanges entre l’utilisateur, l’interface et le serveur.

Technologies vues

  • PHP pour comprendre les bases du développement côté serveur.
  • Node.js pour découvrir un environnement JavaScript côté back-end.
  • Flask pour créer des applications web simples avec Python.

Ce que je comprends

Je sais mettre en place une logique serveur simple, organiser des routes, traiter des informations envoyées par l’utilisateur et préparer des réponses exploitables côté front-end.

Objectif : renforcer mes bases pour créer des applications web plus complètes, reliées à une base de données et mieux structurées.

database

DATABASE

Description

Les bases de données permettent de stocker, organiser et exploiter les informations utilisées par une application web.

Compétences

  • Comprendre la structure d’une table.
  • Créer des relations simples entre plusieurs données.
  • Écrire des requêtes SQL de base.
  • Récupérer, ajouter, modifier ou supprimer des informations.

Utilisation dans un projet

Ces connaissances me permettent de mieux comprendre le lien entre l’interface, le serveur et les données affichées à l’utilisateur.

Objectif : continuer à progresser dans la gestion des données pour créer des applications plus fiables et réellement utilisables.

outils

OUTILS

Description

Les outils de développement m’aident à organiser mon travail, suivre l’évolution de mes projets et comprendre les étapes entre le développement local et la mise en ligne.

Vision globale

Même si je suis principalement orienté développement web, comprendre l’environnement serveur me permet d’avoir une vision plus complète d’un projet.

Objectif : être capable de mieux comprendre le cycle complet d’un site, de sa création jusqu’à sa mise en ligne.
